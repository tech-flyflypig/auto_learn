# 超星自动播放助手

一款 Chrome 扩展(MV3),用于自动化超星学习通的**视频课程播放**与**测验/考试答题**:自动播放、自动切换章节、倍速播放,答题时按"本地题库 → AI 接口"两级策略作答,并自带超星反爬字体的静态映射与运行时解码。

> 仅用于个人学习辅助,请在遵守学校与平台规定的前提下合理使用,由此产生的后果由使用者自行承担。

## 功能特性

**视频自动播放**
- 自动播放课程视频/音频,播完自动进入下一节/下一章
- 支持 1x / 1.5x / 2x / 3x / 4x 倍速,通过劫持 `playbackRate` 属性绕过平台的倍速限制与检测
- 用户主动操作时自动让位(活动看门狗),右上角浮窗实时显示扩展当前在做什么

**自动答题**
- 覆盖章节测验、卡片测验、考试(exam-ans)三类页面
- 两级作答策略:先查本地题库(精确匹配、秒出、confidence 1),未命中再调用 AI
- AI 采用 OpenAI 兼容接口(`/v1/chat/completions`),支持配置任意服务商
- 未命中的题目也会按 AI 最佳猜测作答、不留空;错题不入库,重做时自动用题库纠错
- 考试交卷时间可控:最快交卷时间(按分钟或按题数自动)+ 最晚交卷倒计时强制交卷

**反爬字体解码**
- 内置静态映射表(`cxsecret_map.js`,对应 2026-10 时期字体)+ 运行时解码器
- 运行时解码:提取页面内嵌 base64 TTF → 解析 cmap → canvas 渲染字形与参考字体做相似度匹配 → 生成映射,应对超星字体轮换

**本地题库**
- 提交测验/考试后自动从结果页收割正确答案入库;下次遇到相同题目直接秒答,不再调用 AI
- 收割的真实答案(`harvest`)优先级最高,不会被 AI/导入来源覆盖
- 支持导出/导入 JSON、两步确认清空;存储使用 `chrome.storage.local` + `unlimitedStorage`,无配额压力
- 入库失败(权限/存储异常)会在页面浮窗或设置页明确提示,不再静默丢数据

## 安装

1. 下载/克隆本仓库到本地
2. 打开 Chrome,进入 `chrome://extensions`
3. 打开右上角"开发者模式"
4. 点击"加载已解压的扩展程序",选择本仓库目录

## 使用说明

点击工具栏图标弹出快捷面板:

| 控件 | 说明 |
|---|---|
| 自动播放 | 开关课程视频自动播放(含自动切下一节) |
| 播放倍速 | 视频倍速,即时生效 |
| 自动答题 | 总开关;开启时若 AI 未配置会自动打开设置窗口 |
| 状态行 | 实时显示播放/答题开关与 AI 配置状态 |
| 答题设置 | 打开独立设置小窗口(失焦不关闭,可安心填表) |

### AI 接口设置

在设置窗口的"AI 接口"中填写:

- **接口地址(Base URL)**:填到 `/v1` 为止,如 `https://api.openai.com/v1`、`https://api.deepseek.com/v1` 或任意 OpenAI 兼容网关
- **API Key**:对应服务商的密钥,仅保存在本地 `chrome.storage`,通过 background service worker 代理请求,不会进入网页
- **模型名称**:如 `gpt-4o-mini`、`deepseek-chat` 等
- 点击**测试连接**验证(会先自动保存当前输入)

保存时扩展会为自定义接口域名请求跨域权限(`optional_host_permissions`),请选择允许。

### 答题行为

- **自动提交**:默认开启;关闭则只填充答案,由你手动确认提交
- **最快交卷时间**:从进入考试(开考)算起,不足则倒计时等待,浮窗显示剩余等待时间;`0` = 按题数自动(每题 15 秒、最少 3 分钟)
- **最晚交卷**:距考试结束剩余 N 分钟时,无论等待中还是作答中都跳过等待立即交卷;考试无固定时长时只按最快时间控制

### 本地题库

- 题库以题干归一化文本为键(去【】标注/空白/题号/标点后小写),同一题目无论格式如何变化都能命中
- 数据结构:`chrome.storage.local` 单键 `cx_bank`,值为 `{ question, answer, source, confidence, updated }` 的映射
- **导出**:下载 `cx_bank_日期.json` 全量备份;**导入**:与现有题库按键合并;**清空**:按钮两步确认防误触
- 收割只在结果页公布了正确答案(或你的答案被判对)时进行,结果页无答案则提示"无可收割答案"

## 项目结构

```
├── manifest.json          # MV3 清单:权限、三组内容脚本、background
├── background.js          # Service Worker:AI 代理调用(规避CORS/key不进页面)、题库读写、AI 连通性测试
├── inject.js              # MAIN world 注入:劫持 HTMLMediaElement.playbackRate 绕过平台限速检测
├── content.js             # 播放调度:自动播放、心跳保活、章节/小节导航、状态浮窗、与答题模块协调
├── quiz.js                # 测验模块(doHomeWorkNew):解析题目→查库/AI→填充→提交→结果页收割
├── exam.js                # 考试模块(exam-ans):整卷预览→解析→填充→交卷时间控制→收割
├── font_decode.js         # 反爬字体运行时解码器(base64 TTF → cmap → canvas 字形比对)
├── cxsecret_map.js/.json  # 静态反爬字体映射表(乱码码点 → 真实汉字)
├── popup.html/.js         # 快捷面板:播放/答题开关、倍速、状态、设置入口
├── settings.html/.js      # 独立设置窗口:AI 接口、答题行为、本地题库管理
├── icons/                 # 扩展图标(16/48/128,另附金色备选版 alt_*)
└── tools/                 # 辅助脚本:图标生成、字体 cmap 解析、字形比对等
```

## 工作原理简述

1. **播放**:`inject.js` 在页面主世界劫持 `playbackRate` 的 get/set,使平台读取到的速率与真实速率解耦;`content.js` 在各 iframe 中心跳式维持播放与倍速,监听 `ended` 后点击下一节/下一章。
2. **答题**:测验/考试页的内容脚本解析题目(题干/选项经字体解码还原),发送 `ANSWER_QUERY` 到 background;background 先查 `cx_bank`,未命中的批量转发给 AI,返回后逐题填充;提交后 `harvestAnswers()` 从结果页提取正确答案回写题库。
3. **字体反爬**:超星用自定义字体把部分汉字渲染成乱码码点反爬。静态表覆盖已知字体;字体轮换时 `font_decode.js` 在页面内运行时重建映射(置信度 ≥0.6 才启用),保证 AI 能读懂题干。

## 常见问题

- **测试连接失败?** 检查 Base URL 是否填到 `/v1`(不要带 `/chat/completions`)、Key 是否有效、保存时是否允许了跨域权限;失败信息会显示接口返回的原始错误。
- **倍速没生效?** 平台可能对直播/部分课程强制限速,扩展对这类资源会自动退回原速;另请确认已开启"自动播放"。
- **收割提示"无可收割答案"?** 该次测验结果页未公布正确答案且你的答案未被判定,无法入库,属正常现象。
- **超星更新了反爬字体?** 静态表失效时运行时解码会自动接管;如需更新静态表,可用 `tools/` 下的 cmap 解析与字形比对脚本重新生成。
